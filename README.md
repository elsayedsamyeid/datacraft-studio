## ❓ FAQ

<details>
<summary><b>Is Free really free?</b></summary>
<br>
Yes. No time limit, no connection limit and no account. All eleven data sources are included.
</details>

<details>
<summary><b>Does DataCraft collect data about me?</b></summary>
<br>
No. There is no telemetry. DataCraft only connects to the data sources you add, plus the DataCraft account service if you sign in for Pro.
</details>

<details>
<summary><b>Where are my passwords stored?</b></summary>
<br>
In Windows Credential Manager. They are never written to connection profiles or log files.
</details>

<details>
<summary><b>Is it open source?</b></summary>
<br>
No. DataCraft Studio is free to use but closed source. This page publishes the releases and hosts the issue tracker. See the <a href="LICENSE.md">licence</a>.
</details>

<details>
<summary><b>What about macOS and Linux?</b></summary>
<br>
Windows only for now. Choose <b>Watch → Custom → Releases</b> to hear when other platforms arrive.
</details>
