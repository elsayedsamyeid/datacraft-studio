# Roadmap

This is the direction DataCraft Studio is heading. It is not a set of promises or dates:
priorities change with feedback. [Request a feature](https://github.com/elsayedsamyeid/datacraft-studio/issues/new?template=feature_request.yml)
or 👍 an existing request to influence it.

## Available now — 0.1.6

**Free**

- Eleven data sources: PostgreSQL, SQL Server, MySQL / MariaDB, SQLite, DuckDB, MongoDB,
  Elasticsearch, CSV, Excel, JSON and Parquet
- Connection forms per engine with testing, and passwords in Windows Credential Manager
- Metadata explorer and database-wide object search
- Query editor with engine-aware autocomplete, snippets and placeholders
- Command palette
- Result grid with typed headers, aggregates, JSON viewer, CSV and Excel export, and large
  streamed exports

**Pro** — [on request](guide/pro-and-accounts.md#getting-pro)

- Visual query builders for SQL, MongoDB and Elasticsearch
- Query history and a saved workspace
- Guided data import wizard
- Data migration between engines
- Provider health checks
- AI assistant with your choice of model provider

## Next

- **Pro pricing and online purchase**, so Pro no longer needs a manual request
- **Code-signed installers**, so Windows shows DataCraft as a verified publisher
- **In-app update notifications** for new releases, installed only with your consent
- **An About screen** showing the installed version

## Later

- **macOS and Linux builds**
- More data sources — tell us which you need
- Team features for sharing workspaces and connection templates
