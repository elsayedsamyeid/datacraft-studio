## Writing a good report

- Say which **version** you run (Windows Settings → Apps → Installed apps → DataCraft Studio)
  and your **plan** (Settings → Features → Plan).
- Include the **data source** and its version, and the exact **steps** and **error text**.
- **Never post** passwords, connection strings, API keys, your full email address, or private
  data. Issues are public.

## What to expect

DataCraft Studio is maintained by a small team. Reports are read and triaged as quickly as
possible, without a guaranteed response time. Security reports are acknowledged within
5 working days. Only the latest release receives fixes, so please update before reporting.
