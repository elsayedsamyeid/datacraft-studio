# Keyboard shortcuts

## Anywhere

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Open the command palette |

In the command palette, start with a prefix to narrow the search:

| Prefix | Searches |
| --- | --- |
| `>` | Commands |
| `@` | Connections |
| `#` | Tables and other resources |

Use the arrow keys, <kbd>Home</kbd>, <kbd>End</kbd>, <kbd>Page Up</kbd> and <kbd>Page Down</kbd> to move, and <kbd>Enter</kbd> to open.

## Query tabs

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | New query tab |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Close the current tab |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Next tab |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | Previous tab |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> … <kbd>9</kbd> | Jump to tab 1–9 |
| <kbd>F2</kbd> | Rename the focused tab |

## Query editor

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Run the selection, or the whole query if nothing is selected |
| <kbd>Ctrl</kbd>+<kbd>Space</kbd> | Show suggestions |
| <kbd>Ctrl</kbd>+<kbd>/</kbd> | Comment or uncomment lines |
| <kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>A</kbd> | Block comment |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo (accepting a suggestion is a single undo step) |

## Suggestions popup

| Shortcut | Action |
| --- | --- |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move through suggestions |
| <kbd>Enter</kbd> | Insert the suggestion or snippet |
| <kbd>Tab</kbd> | Insert and continue, or jump to the next snippet placeholder |
| <kbd>Shift</kbd>+<kbd>Tab</kbd> | Previous snippet placeholder |
| <kbd>Esc</kbd> | Close |

## Explorer

| Shortcut | Action |
| --- | --- |
| <kbd>Enter</kbd> | Connect or disconnect a connection; run an object's default action |
| <kbd>Space</kbd> | Select the item |
| <kbd>F5</kbd> | Refresh the connection or item |
| <kbd>Shift</kbd>+<kbd>F10</kbd> | Open the item's action menu |

## Results grid

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy the selected cells |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Copy the selected cells with column headers |

Right-click for more copy formats: CSV, TSV, JSON and Markdown.
